Объём:
Добавить DiscussionMessage (comment, decision, question, steer, system), миграцию storage discussion, типизированную команду attempt.steer для безопасного направления активной попытки, ссылку на полную DSH-сессию и audit для решений. Маршруты /v1/tasks/{id}/discussion и /v1/attempts/{id}/steer регистрирует эта карточка поверх Application API, открытого MW-029, через ctx.webServer. Полный чат в карточку не копируется: только ссылки, краткие сообщения, решения и audit trail.

Приёмка:
Steering активной попытки идёт только типизированной командой, проверенной по permissions и frozen revisions; прямой записи в session store нет. Steer по не-running attempt отвергается типизированной ошибкой и не имеет эффекта. Ни один тест не находит транскрипт сессии в строках карточки или сообщения. Повтор steer с тем же operationId даёт один эффект. decision-сообщение пишет строку audit. Ссылка на несуществующую сессию даёт SESSION_NOT_FOUND.
