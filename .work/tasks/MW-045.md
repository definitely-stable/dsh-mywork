Приёмка:
Переход в done без обязательного evidence отвергается с FINISH_CRITERIA_UNMET и называет отсутствующий ArtifactKind. Для каждого из шести work types resolveFinishCriteria возвращает различный набор. non-git-ops не создаёт worktree (проверяется отсутствием вызова worktree-порта). manual требует receipt-артефакт. Интегратор artifact-publish записывает получателя в evidence. Существующие ArtifactKind сохраняют прежнее значение и ни одно сохранённое значение не переинтерпретируется.
