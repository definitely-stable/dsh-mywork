Объём:
Реализовать selection и multi-select, bulk-команды с per-card результатом, полную клавиатурную модель, drag-and-drop с подсветкой только легальных целей и обязательной причиной для error/blocked/cancelled, command palette «Переместить…», detail panel (Обзор, Обсуждение, Попытки, Review, Evidence, Зависимости, Workflow, История, Сессии), поиск, фильтры, saved views, dependency preview, рендер review/evidence/blocked и ссылки на полные DSH-сессии.

Приёмка:
Keyboard-only проход выполняет все действия: выбор, перемещение, bulk, открытие detail, поиск. DnD не пишет board state напрямую и подсвечивает только легальные цели. Drop в error/blocked/cancelled без выбранной причины отклоняется. Два одинаковых DropIntent с разными operationId не меняют состояние дважды. Bulk move предлагает только цели, легальные для всех выбранных, и возвращает результат по каждой карточке. Saved view сохраняется и восстанавливается с density, layout, фильтрами и сортировкой. Detail panel закрыт по умолчанию. Dependency preview показывает зоны и состояния прямых соседей. Session link открывает реальную DSH-сессию. «Остановить и отменить» доступно только на running-карточке и отличимо от «Отменить»; после него в карточке виден artifact diff. Баннеры blocker-void и staged-recovery рендерятся в полосе, а три действия recovery доступны и без UI. Карточка показывает конкретный NeedsAttentionReason, а не общее «требует внимания».
