Объём:
Добавить декларативный WorkflowRevision (contracts/src/workflow.ts) и core/src/workflow.ts: типизированные узлы (start, step, verify, ai-review, human-approval, integrate, retry, branch, parallel/join, escalate, end), закрытый язык условий с каталогом полей, валидатор без escape hatch. Реализовать один engine внутри resident controller: frozen workflow revision на attempt, L2 по умолчанию, L3 с авто-утверждением только additive-планов, human gates, bounded retries, timeout, escalation, recovery после restart, идемпотентные node generations, отсутствие дубля старта после SSE reconnect.

Приёмка:
Engine не адмитит сам: счётчик admission-вызовов показывает scheduler единственным адмитером. validateWorkflow отвергает неизвестный node kind, неизвестный VerificationId, неизвестное поле условия, цикл и любой документ с ключом shell/command/exec. evaluateCondition тотально определена на закрытом каталоге полей и не содержит eval. После restart посередине workflow engine возобновляется в верном узле и не создаёт дублирующих attempts. L3 авто-утверждает только additive-мутацию (create + dep_add) и записывает классификацию в audit; не-additive план под L3 поднимает human gate. Ни один HUMAN_GATES не закрывается автоматически. Reviewer с тем же agentId, что и worker, отвергается с SECURITY_DENIED. Предикат автоутверждения L3 — чистая функция (класс additive-only, непустые claims у каждой новой задачи, отсутствие пересечений с существующими, work type из разрешённого набора, ни одного HUMAN_GATES) и монотонен: property-тест показывает, что удаление или пересекающийся claim переводят только true→false, но никогда обратно. План без claims под L3 поднимает гейт и называет непройденное условие. review.request-evidence без findings отвергается; новая попытка несёт типизированное поле evidenceRequest и расходует retry-бюджет; исчерпание бюджета даёт needs-attention с причиной retry-exhausted; escalated не переоткрывается и всегда порождает human gate.

Ограничения исполнения: одна карточка за запуск; не переходи к следующей. Используй существующие patterns/DSH API/stdlib, без speculative scaffolding.
