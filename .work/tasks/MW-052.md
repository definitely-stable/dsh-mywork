Объём:
Реализовать представление зависимостей (DAG), calendar по due/defer и опциональный timeline по startedAt/settledAt на собственной SVG-раскладке по слоям, без новых npm-зависимостей. Доступность узлов и рёбер для клавиатуры и для assistive technology.

Приёмка:
Ни одной новой npm-зависимости в package.json затронутых пакетов. Узлы и рёбра достижимы с клавиатуры (roving tabindex) и имеют текстовые имена для screen reader. Цикл не рисуется как валидный граф: отказ отображается явным сообщением. Calendar строится по due и defer и совпадает с данными карточек. Граф на 1000 узлов не блокирует UI (окно по уровням или пагинация).
