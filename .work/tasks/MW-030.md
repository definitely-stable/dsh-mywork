Объём:
Реализовать autonomy L0–L3 и operation gates для миграций/security/release/production. Команды Pause/Cancel/StopAfterCurrentTool/Reassign/Retry: revoke lease, fence++, stop runtime, checkpoint/evidence, retention и graph transition. Плюс контракт AutonomyLevel (L0–L3 по §28), при этом шкала progressive disclosure контекста из §21.2 переименовывается в D0/D1/D2, чтобы одна нотация не означала две разные вещи. Плюс TaskClaims { paths, labels } и PlanMutationClass (additive-only, modifying, destructive) с детерминированным вычислением. Плюс команда task.stop-and-cancel как композиция трёх существующих переходов: attempt → cancelled (требует текущий fence), task executing → ready, task ready → cancelled с причиной; diff worktree сохраняется как artifact diff до отмены, и при неудачной записи artifact команда отказывает. Плюс каталог NeedsAttentionReason с детерминированными условиями и названным источником для каждого триггера.

Приёмка:
Cancel при активном tool и позднем result не коммитит stale изменения. Pause не теряет работу; retry идемпотентен. Human override аудируется; повышение автономности не возникает из prompt/learning. Stop-and-cancel на running-задаче даёт ровно одну попытку в cancelled, задачу в cancelled и artifact diff. Неудачная запись artifact оставляет задачу в executing. Устаревший fence даёт STALE_FENCE и ничего не меняет. Cancel без композиции на running-задаче отвергается типизированной ошибкой с именем легальной команды. Каждый из семи триггеров needs-attention достижим тестом, проверяющим и состояние, и точную причину; ни один путь не ставит needs-attention без причины.
