## Как стартовать (этап 0)

**Три условия старта** (из red-team): шаги брать из `20-STEPS-foundation.md`, а не из разделов мастер-плана; соблюсти обязательное ребро `F-02/F-03 (копия профиля) → F-04 (гейт прав)`; зафиксировать числовой бюджет кампании (`01-MASTER-PLAN.md` §17 — предложение Lead'а: ≤10 запусков карточек в сутки, стоп при двух подряд инфраструктурных отказах).

1. `F-01` — починить runner: канон `corepack pnpm -r run <script>` (`-r` обязателен).
2. `F-02` → `F-03` — внешняя копия `C:\Users\Dmitry\.dsh` и проверенная процедура восстановления.
3. `F-04`/`F-05`/`F-61` — поднять `sessionDefaultPermission` на уровень `config`, убрать мёртвые `autoRun*`, зафиксировать `mode: cordis`; затем `F-06` и `F-62` (доказать, что гейт прав снят).

**Безопасность удалений.** Чистка `.tmp`/`.rar`/worktree — только по правилам изоляции: в `.tmp` **543 reparse-точки, 21 из них ведёт в живое дерево**, поэтому рекурсивное удаление по вычисленному пути запрещено; рекурсивно безопасны только `f-audit/node_modules`, `mw012-review/node_modules` и нулевой мусор. Подробности — `evidence/lead-18-cleanup.md`.
