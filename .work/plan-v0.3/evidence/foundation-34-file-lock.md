## Шаг 0 плана: какие файлы состояния пишутся вне SQLite

`Select-String packages\storage\src\*.ts -Pattern 'withFileLock'` до работы → 0 совпадений; вне SQLite сегодня **не пишется ни один** файл состояния. Шаг не отложен (план допускал отсрочку при пустом списке), потому что примитив нужен двум ближайшим потребителям MW-040: экспорт/импорт и backup-манифест, а `tests/storage/file-lock.test.mjs` использует обычный файл — то есть лок проверен на реальном файле, а не на заглушке.

**Список файлов, к которым лок применяется сейчас:** нет ни одного боевого (примитив публикуется для MW-040).
**К чему лок НЕ применяется:** `.sqlite` — у SQLite своя сериализация (`BEGIN IMMEDIATE` + `busy_timeout`), второй слой дал бы взаимоблокировки (митигация риска из плана).

## Реализация (кратко)

`withFileLock(target, body, options?)`: лок-файл `<target>.lock` создаётся с флагом `wx` (O_EXCL) и телом `{"pid":…,"at":…}`; при `EEXIST` — проверка «заброшенности» по `at` (fallback — mtime) с порогом `staleMs` (по умолчанию 30 с), затем повтор каждые 10 мс до `timeoutMs` (5 с); по исчерпании — `StorageError` с кодом `lock-timeout`. Лок снимается в `finally`, значение/ошибка `body` проходят наружу без изменений.

Тесты: (1) второй держатель не входит в критическую секцию и получает типизированный `lock-timeout` (тело второго не выполнилось), после освобождения лок-файла нет; (2) лок освобождается и повторно берётся, заброшенный лок (`at: 1`, `staleMs: 50`) ломается, а тело, бросившее ошибку, всё равно снимает лок.

## Что не проверено

- **Два реальных процесса** на одном файле: сценарий воспроизведён двумя вызовами в одном процессе. Межпроцессная дисциплина держится на `O_EXCL` (атомарность создания файла — гарантия ОС), но эксперимент с двумя `node`-процессами не ставился.
- Гонка «оба увидели лок заброшенным» (`staleMs` истёк у обоих): оба попытаются `unlink` и `wx`-создать; один победит, второй получит `EEXIST` и продолжит ждать. Отдельным тестом не покрыто.
- `withFileLock` не применялся ни к одному боевому файлу (потребителей пока нет, см. шаг 0).
