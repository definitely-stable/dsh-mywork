### N1 — MINOR: новое поле ростера не валидируется, при строковом значении гейт молча переходит на подстрочное сравнение

- **Файл:** `packages/core/src/scheduler.ts:501` (проверка) и `:709-734` (`requireTickInput`, где валидации нет).
- **Что не так:** `workspace.agentIds !== undefined && !workspace.agentIds.includes(identity.id)`. Если вызывающий передал строку вместо массива, работает `String.prototype.includes`, то есть **подстрочное** сравнение вместо членства в списке. Проба `.tmp/mw014-fixes-verify/probe-roster-type.mjs` на копии артефакта:
  - ростер `['Neo-1']` → допуск `Neo-1`; ростер `['Neo-9']` → `agent-not-in-workspace` (корректно);
  - ростер **`'xNeo-1x'`** (строка) → `admissions=1` — identity `Neo-1` **допущена**, хотя в ростере её нет; строка `'Neo-9'` → отказ (то есть поведение зависит от содержимого строки, а не от формы);
  - ростер `{}` → `TypeError: workspace.agentIds.includes is not a function` — падает громко, но сообщение не по конвенции модуля (`dsh-mywork: … must be …`), и оно не называет поле;
  - ростер `[42]` и `[]` → отказ всем (fail-closed, безопасно).
- **Почему важно:** ростер — единственный фильтр, которым фикс F2 заменил вырожденный §31-гейт, то есть несёт security-смысл (членство в `Team.agentIds`, §6.1). Направление отказа — **fail-open**: identity, которой в ростере нет, получает работу. Модуль при этом декларирует обратную конвенцию: «a malformed tick is a programming error» — и валидирует все прочие вложенные поля (`nowMs`, `scheduling.weight`, элементы `instances` через `requireResourceState`). `agentIds` — единственное новое поле тика, которое молча меняет семантику вместо `TypeError`, и ровно такое значение («`"Neo-1, Neo-2"`» — ростер, склеенный вызывающим из конфигурации) приводит к подстрочным допускам.
- **Минимальная правка:** в `requireTickInput` рядом с проверкой `weight`:
  ```ts
  const roster = workspace.agentIds
  if (roster !== undefined && (!Array.isArray(roster) || roster.some(id => typeof id !== 'string' || id.trim() === ''))) {
    throw new TypeError(`dsh-mywork: the roster of workspace "${workspace.workspaceId}" must be an array of non-empty identity ids`)
  }
  ```
